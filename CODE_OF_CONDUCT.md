# Code of Conduct

Nexora is built for and with gig workers. Everyone who takes part, in issues, pull requests or anywhere else the project meets, is expected to:

- be respectful, whatever someone's language, background, job or level of experience;
- write plainly so that people reading in a second language can follow;
- never post anyone's personal details (names, phone numbers, rider IDs, screenshots that show them) without their consent;
- disagree about ideas, not people.

Harassment, threats, slurs and doxxing are not tolerated. Maintainers may remove content and block people who break these rules.

To report a problem, contact the maintainers privately through a [GitHub security advisory](https://github.com/GuTS805/Nexora/security/advisories/new). Reports are kept confidential.

This code is adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org).
